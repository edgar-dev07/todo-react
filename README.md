# Todo React

Proyecto de aprendizaje desarrollado con **React + Vite**.
El objetivo es aprender y practicar los principales conceptos de React mediante la construcción de una aplicación de tareas (Todo App).

## 🚀 Tecnologías

* React
* Vite
* JavaScript / TypeScript
* HTML
* CSS
* SVG
* Git & GitHub

## 📚 Temas de aprendizaje

Durante el desarrollo del proyecto se trabajarán los siguientes conceptos:

### React Fundamentals

* Componentes
* Props
* Atributos
* Eventos
* Renderizado condicional
* Listas y `key`
* Manejo de estados
* Efectos de React
* React Context
* `useContext`

### Hooks

* `useState`
* `useEffect`
* `useContext`
* Custom Hooks

### Persistencia

* `localStorage`
* Persistencia del estado de la aplicación

### UI e iconos

* Uso de iconos
* Librerías de iconos
* SVG
* Creación y reutilización de componentes visuales

### Arquitectura y organización

Se aplicará una organización **Feature-First**, agrupando los archivos según la funcionalidad a la que pertenecen.

También se practicarán:

* Organización de carpetas
* Naming conventions
* Abstracción de componentes
* Componentes reutilizables
* Separación de responsabilidades

Ejemplo:

```text
src/
├── app/
├── features/
│   └── todos/
│       ├── components/
│       ├── hooks/
│       ├── pages/
│       └── services/
├── shared/
│   ├── components/
│   ├── hooks/
│   └── utils/
└── main.jsx
```

## 🔄 Migración y actualización

Como parte del aprendizaje, el proyecto también servirá para practicar la **migración entre versiones de React y otras dependencias**, revisando cambios, incompatibilidades y buenas prácticas de actualización.

## ☁️ Deploy

El proyecto será publicado utilizando **GitHub**, con el objetivo de practicar:

* Git
* GitHub
* Repositorios
* Commits
* Branches
* Deploy de aplicaciones frontend

## 🎯 Objetivo

El objetivo principal es construir una base sólida en **React**, entendiendo no solo cómo utilizar sus herramientas, sino también cómo organizar y estructurar un proyecto frontend de forma mantenible y escalable.

Este proyecto forma parte de mi proceso de aprendizaje de **React + Vite**.
